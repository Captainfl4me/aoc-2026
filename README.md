# 🎄 Advent of Code 2026 🎄

My solutions for [Advent Of Code 2026](https://adventofcode.com/2026), in Python 🐍.

## Use template

To create a new day simply run: ```make new-day-NUMBER_OF_DAY```.

It creates the input files in the `aoc-2026-inputs` submodule and copies the
`template-day` scaffold into `day-XX/`.
